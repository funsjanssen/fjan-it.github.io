Getting Started with Azure DevOps AI Assistant Extension

Welcome to the Azure DevOps AI Assistant Extension! This guide will help you get started with using the extension effectively to enhance your work items with AI-powered content generation.

Overview

Enhance your Azure DevOps work items with AI-powered generation of descriptions and acceptance criteria. This extension leverages OpenAI to help your team create high-quality work items faster and more consistently.

Key Features

  • 🤖 AI-Powered Content Generation: Automatically generate descriptions and acceptance criteria using custom prompts
  • 🎯 Custom Prompt Management: Create and manage organization-wide custom prompts tailored to your team's needs
  • ⚡ Quick Integration: Seamlessly integrated into Azure DevOps work item forms
  • 🔍 Review & Confirm: Preview and approve AI-generated content before saving

Installation

To install the Azure DevOps AI Assistant Extension, follow these steps:

  1. Open your Azure DevOps organization.
  2. Navigate to the "Marketplace" section.
  3. Search for "Azure DevOps AI Assistant Extension".
  4. Click on "Install" and follow the prompts to add it to your project.

How It Works

1. Create Custom Prompts

Create custom prompts at the organizational level. This allows you to create prompts that are available to all users in your organization. Work item context is available in the prompt, so you can create prompts that are specific to the work item type and field.

You can use HTML formatting in your prompts to create more complex content.

2. Access Prompts from Work Item Forms

Access prompts directly from work item forms.

3. Generate Content

Select your prompt and generate the desired content.

4. Review and Confirm

Review and confirm the AI-generated content before applying it to the work item. Then you can save the work item.

Roadmap

Privacy & Security

Getting Started Steps

  1. Install the extension from the Azure DevOps marketplace
  2. Configure your organization settings
  3. Create your first custom prompt or use one of the default prompts
  4. Start generating content in your work items
