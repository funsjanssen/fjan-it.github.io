Frequently Asked Questions

  1. Install the extension from the Azure DevOps marketplace
  2. Configure your organization settings
  3. Create your first custom prompt or use one of the default prompts
  4. Start generating content in your work items

The extension only processes the work item data that you explicitly choose to generate content for. No data is stored on our servers, and all processing is done in real-time. We take your privacy seriously and ensure that your data remains secure.

Custom prompts can be created at the organizational level through the extension settings. You can use HTML formatting and include work item context variables to create dynamic prompts that adapt to your specific needs.

The extension works with any modern web browser and requires an active Azure DevOps organization. No additional software or hardware is required.
